# Data card

This folder holds the prompt sets built by `src/build_prompts.py`. The public copy, with
licence-based redaction, is in `release/data/`.

## Files

| File | Rows | What it is |
|---|---|---|
| `prompts_replication.csv` | 500 | C4 RealNewsLike documents, paper protocol: the last 200 OPT tokens are held out as the human baseline and the rest (≤ 312 tokens) is the prompt |
| `prompts_multidomain.csv` | 1,000 | 100 documents from each of 10 sources: the first 50 OPT tokens are the prompt and the next 150 are the human continuation |
| `prompts_multidomain_qwen.csv` | 1,000 | the same documents re-tokenised for Qwen2.5 (`src/retokenize_prompts.py`); prompt and human text unchanged |
| `prompts_*_report.json` | – | per source: documents scanned and kept, every rejection by reason, cleaning edits (PII replacements, code blocks removed, hyphenation joins), median document length, one raw-vs-clean example |

## Columns (prompt files)

`prompt_id`, `source`, `domain`, `subdomain`, `protocol` (suffix/prefix), `prompt`, `human` (held-out
continuation), `prompt_ids` / `human_ids` (exact OPT token ids, space-separated; the prompt starts with
BOS), `prompt_tokens`, `human_tokens`, `doc_tokens`, `source_dataset`, `source_config`, `source_split`,
`source_revision`, `source_row_index` (position in the seeded shuffled stream), `source_doc_meta` (JSON:
title/url/id/subreddit/site...), `licence`, `redistributable`, `prompt_sha256`, `tokenizer`.

## Generated data (`results/<experiment>/generations.csv`)

There is one row per (text, detector γ). `condition` ∈ {human, unwatermarked, watermarked}. `gamma`/`delta` is the
watermark used for generation. `modification` is `none` or an edit attack (`delete_0.3`, `random_substitute_0.5`,
`synonym`, `whitespace`; T5 attacks are in `attacks_t5.csv`). The scores are `green_fraction`, `z`, `p_value`,
`detected` (z > 4), the repeated-bigram-ignored `z_dedup` / `detected_dedup`, `z_at_{25,50,100,150,200}`, and
`distinct2`. Unmodified texts keep their exact `token_ids`. All model text is machine-generated by OPT-1.3B
(`replication`, `multidomain`) or Qwen2.5-1.5B (`multidomain_qwen`) and is labelled as such.

## Collection and preprocessing

1. Each source is streamed with a seeded shuffle (seed 42, buffer 2,000), so the sample is reproducible.
2. Text is normalised with Unicode NFKC, then per-source markup is removed: HTML and `<pre>` code from Stack Exchange,
   `<br />` from IMDb and Amazon, licence headers and front matter from Gutenberg, and hyphenation and hard wraps
   from the PDF-extracted ethics statements.
3. E-mails, URLs, phone numbers and Reddit usernames are replaced with placeholders.
4. Documents are rejected if they are short (< 600 characters), not prose (< 55% letters), in a non-Latin script,
   heavy on markup, heavy on links or contact details, or explicit/abusive (informal sources, keyword list and
   NSFW subreddit names).
5. The span starts at the first sentence boundary and is cut into a 50-token prompt and a 150-token human continuation.
6. Prompts are de-duplicated by hash.
